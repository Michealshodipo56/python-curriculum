# listtotal

## Description
Read one line of space-separated integers. Print their sum. The line may be empty.

## Requirements
An empty collection has a sum of zero.

## Examples
Input: "1 2 3\n" → output: "6\n"

Input: "-5 8 -3\n" → output: "0\n"

## Tips
Convert each token to an integer before adding. You can accumulate values while iterating.
