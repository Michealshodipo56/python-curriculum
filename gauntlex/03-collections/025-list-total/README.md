# Sum the Collection

## Description
Turn a sequence of numeric inputs into a single total. Your program must also handle the absence of values.

## Requirements
- Read one line of space-separated integers; it may be empty.
- Display their arithmetic sum as one integer.
- An empty collection has a sum of zero.

## Example
Input: `1 2 3` → output: `6`. Input: `-5 8 -3` → output: `0`.

## Tips
Input arrives as text, but arithmetic requires numbers. Think about how the total changes as each element is visited.

The example illustrates the expected result, not a solution.
