# Gauntlex Python — 409 Challenges

The curriculum contains 409 independent challenge packages across 23 sections. Follow [the learning path](../GAUNTLEX_LEARNING_PATH.md) in numeric challenge order, including core projects 311–314 and final projects 405–409.

## Start here

Use Python 3.11 or later. Read the challenge README before editing its incomplete starter. Work from that challenge’s directory; the starter path and callable or command-line interface are part of its contract. Use the standard library unless the brief states otherwise. The existing pytest checks are contract evidence; unfinished starters are expected to fail.

## Source acknowledgments

The problem-first format is inspired by 01-edu. The source collection includes 30 Days of Python, C1-Code-Crunch-Convos, learn.python, and Exercism Python. Their pinned source directories, licenses, source review notes, and the historical 693-activity inventory are retained. The 409 authored challenges do not imply one-to-one coverage of those 693 activities. See [the pinned source review notes](SOURCE_REVIEW_NOTES.md) for the limits of existing mappings.
