# digitcount

## Description
Read an integer and print the number of decimal digits in its absolute value.

## Requirements
The number 0 has one digit. A leading minus sign is not a digit.

## Examples
Input: "0\n" → output: "1\n"

Input: "-1204\n" → output: "4\n"

## Tips
Repeated integer division by ten removes one decimal digit at a time. Consider zero separately.
