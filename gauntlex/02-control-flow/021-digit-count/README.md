# Decimal Length

## Description
Determine how many decimal digits an integer contains, ignoring its sign.

## Requirements
- Read one integer.
- Display the number of digits in its absolute value.
- Treat zero as a one-digit number; do not count a minus sign.

## Example
```text
Input:
-1204

Output:
4
```

## Tips
Try the cases 0, 9, 10, and −10 before generalizing. What changes each time another decimal digit appears?

The example demonstrates expected behavior; it does not reveal an implementation.
