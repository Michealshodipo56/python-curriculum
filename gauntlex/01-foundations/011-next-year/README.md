# nextyear

## Description
Read a person's name and their current age as an integer, each on a separate line. Display a sentence giving their age next year.

## Requirements
- Assume a nonnegative age.
- Use the exact sentence `NAME will be AGE next year.`
- Do not print prompts.

## Examples
Input `Mira` and `19` produces `Mira will be 20 next year.`

## Tips
Input starts as text. A number can be converted to an integer before arithmetic. You can combine a name and a computed number in a formatted message.
