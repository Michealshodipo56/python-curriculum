# twolines

## Description
Write a program that displays `Python` on the first line and `Gauntlex` on the second line.

## Requirements
- Name the file `main.py`.
- Output exactly two lines, in order.
- Include the final newline.

## Examples
```text
Python
Gauntlex
```

## Tips
A newline separates one line of output from the next. Think about what happens when output is displayed more than once.
