# Two Signals

## Description
A program can communicate more than one piece of information. Display two separate messages in a precise order.

## Requirements
- Work in `main.py`.
- Display `Python` on the first line and `Gauntlex` on the second.
- Do not insert blank lines or other output.

## Example
```text
Python
Gauntlex
```

## Tips
Observe how the terminal distinguishes consecutive lines. Consider whether one output operation or multiple operations could satisfy the contract.

The example illustrates expected behavior; it is not an implementation.
