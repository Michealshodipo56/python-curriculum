# Observation Counts

## Description
Summarize a dataset by recording how often each integer appears.

### Behavior contract
Return a dictionary mapping each integer in the input to its count.

## Requirements
- Implement `frequency_table(values)` in `starter/solution.py`.
- Return the result; do not print or read standard input.
- Do not mutate the input lists.
- Use only the Python standard library.

## Examples
`frequency_table([1, 2, 1])` → `{1: 2, 2: 1}`

`frequency_table([])` → `{}`

## Tips
An empty dataset should produce an empty frequency mapping.

Examples illustrate expected values, not a solution.
