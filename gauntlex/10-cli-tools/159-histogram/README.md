# histogram

## Challenge
Read whitespace-separated nonnegative integers from standard input. For each distinct integer in ascending order, print `VALUE: COUNT` on its own line.

## Requirements
- Implement in `starter/main.py` using standard input and standard output.
- Print no prompts, debug messages, or explanatory text.
- Use the Python standard library only.
- Match the required output exactly, including line endings.

## Examples
Input: "3 1 3 2 1 3\n"

Expected output: "1: 2\n2: 1\n3: 3\n"

Input: ""

Expected output: ""

## Hints
A frequency dictionary and sorted keys produce deterministic output.
