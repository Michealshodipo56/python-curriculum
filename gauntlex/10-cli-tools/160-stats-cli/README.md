# statscli

## Challenge
Read whitespace-separated integers from standard input. Print `count=N`, `sum=S`, `min=M`, `max=X` on separate lines. For empty input print only `count=0` and `sum=0`.

## Requirements
- Implement in `starter/main.py` using standard input and standard output.
- Print no prompts, debug messages, or explanatory text.
- Use the Python standard library only.
- Match the required output exactly, including line endings.

## Examples
Input: "3 1 2\n"

Expected output: "count=3\nsum=6\nmin=1\nmax=3\n"

Input: ""

Expected output: "count=0\nsum=0\n"

## Hints
Handle empty input before computing minimum and maximum.
