# anagram

## Description
Implement `are_anagrams(a, b)` returning True if both strings contain the same characters with the same multiplicities. Comparison is case-sensitive.

## Requirements
- Implement the named function in `solution.py`.
- Return the value; do not print it.
- Do not add executable input handling at module import time.

## Examples
`anagram("listen", "silent")` → `True`

`anagram("aab", "abb")` → `False`

## Tips
Frequency counts or sorted character sequences can reveal whether multiplicities match.
