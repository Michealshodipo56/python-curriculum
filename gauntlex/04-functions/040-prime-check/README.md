# prime

## Description
Implement `is_prime(n)` returning True only when integer n is prime. Numbers below 2 are not prime.

## Requirements
- Implement the named function in `solution.py`.
- Return the value; do not print it.
- Do not add executable input handling at module import time.

## Examples
`prime(2)` → `True`

`prime(17)` → `True`

## Tips
A divisor greater than one and smaller than n proves n is composite. You can stop searching early.
