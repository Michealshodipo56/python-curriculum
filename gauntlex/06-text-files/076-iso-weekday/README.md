# iso_weekday

## Description
Return the ISO weekday of a valid YYYY-MM-DD date: Monday=1 through Sunday=7.

## Requirements
- Implement `iso_weekday(text)` in `starter/solution.py`.
- Return the required value without printing or prompting.
- Use the standard library only and do not mutate input collections.

## Examples
`iso_weekday("2024-01-01")` → `1`

`iso_weekday("2024-01-07")` → `7`

## Tips
Date objects expose an ISO weekday method.
