# days_between

## Description
Return the absolute number of days between two valid ISO date strings.

## Requirements
- Implement `days_between(a, b)` in `starter/solution.py`.
- Return the required value without printing or prompting.
- Use the standard library only and do not mutate input collections.

## Examples
`days_between("2024-01-01", "2024-01-03")` → `2`

`days_between("2024-03-01", "2024-02-28")` → `2`

## Tips
Subtract date objects to obtain a duration.
