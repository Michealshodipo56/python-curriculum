# safe_divide

## Description
Return a/b, or None if b is zero.

## Requirements
- Implement `safe_divide(a, b)` in `starter/solution.py`.
- Return the required value without printing or prompting.
- Use the standard library only and do not mutate input collections.

## Examples
`safe_divide(8, 2)` → `4`

`safe_divide(3, 0)` → `None`

## Tips
Handle only the expected division-by-zero case.
