## 30 Days of Python

- `02_Day_Variables_builtin_functions/02_variables_builtin_functions.md`: the casting example computes `int(float('10.6'))` but then attempts `int(num_str)` with `num_str='10.6'`, which raises instead of producing the commented10. Do not present this as a valid conversion example.
- `03_Day_Operators/03_operators.md`: examples use `is` for numeric value equality and describe it through equal data values. Teach identity versus equality explicitly and use `==` for value comparisons. Slope formula needs parentheses; mathematical `x^2` means Python `x**2`. Invalid direct float-text conversion is an error investigation, not a successful comparison.
- `04_Day_Strings/04_strings.md`: numbered questions23/26 and25/27 repeat the same requests. Company replacement uses inconsistent Coding/coding case; strip prompt contains rendered HTML-space entities. Record exact duplicates and clarify displayed input.
- `05_Day_Lists/05_lists.md`: basic mutation questions form a cumulative chain. Later tasks introduce statistics, imported datasets, parity and starred unpacking, so the whole chapter cannot be assigned as initial list practice.
- `06_Day_Tuples/06_tuples.md`: full lesson and exercises read. Tuple values cannot be changed, but the container may hold mutable objects; concatenating parent names creates a new tuple. Deleting a variable is not guaranteed object destruction if aliases remain. The sibling-name prompt must supply the two tuples referenced in the next item.
- `07_Day_Sets/07_sets.md`: full lesson and exercises read. `set.pop()` removes an arbitrary element, not a statistically random choice. A set is mutable; the statement that existing items cannot change refers to replacing an individual member, not container immutability. `update` accepts general iterables, not only lists. Do not rely on display order.
- `08_Day_Dictionaries/08_dictionaries.md`: full lesson and exercises read. Dictionary insertion order is guaranteed in the supported modern Python version. `keys`, `values` and `items` return views, not lists; task requests for lists need explicit conversion. `copy()` is shallow, so nested mutations can remain shared. The deletion example misspells `is_marred` versus `is_married` and would raise KeyError.
- `09_Day_Conditionals/09_conditionals.md`: full exercise section read; lesson not yet fully reviewed. Level2 and3 question indentation differs from most chapters; extraction must retain them. Seasons use the exercise's stated convention, not a global climatic rule. Developer-label rules overlap and need documented branch priority; do not infer actual career qualifications from a few strings.
- `10_Day_Loops/10_loops.md`: full exercise section read. Country-language tasks need dataset loading, nested dictionaries, aggregation and sorting beyond loop syntax. Their source links include inconsistent hyphen/underscore filenames; validate local dataset before assignment.
- `11_Day_Functions/11_functions.md`: full exercise section and final argument examples read; earlier lesson still pending. `convert_celsius_to-fahrenheit` and `check-season` contain illegal identifier hyphens; use valid underscored names with an explicit note. Higher-order lesson example `square_number(n)` returns `n**n`, not a square. Statistical function suite needs formulas and a stated sample/population convention; it is not an introductory two-parameter function.
