# Unified Python Curriculum — Master Task Order

> **Status: source-derived draft, not yet a manually verified final syllabus.** This file inventories concrete task references from all four source curricula and interleaves them by prerequisite themes. Repository trees and published indexes were inspected; **every individual task body has not yet been manually reviewed**, and this order requires dependency-by-dependency validation before enforcing unlocks. No solutions are included.

## Source integrity

The root repository [python-curriculum](https://github.com/Michealshodipo56/python-curriculum) currently contains **four Git submodule pointers**, not four ordinary copied source trees. Links below therefore target the source repositories directly. Exercism's curriculum is sourced from its official track configuration; the other three are from the user's forks. This is an index of tasks, not a rewrite of their content.

**Task sequence rule:** complete items top to bottom within a stage; tasks in the same stage may be reordered after checking their individual instructions. Optional exercises and capstones should be distinguished during final review. Source code with answers/solutions must never be exposed as learner tasks.
